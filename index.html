⬇ 윈도우용 다운로드
Windows 10 / 11 · 무료

이런 걸 해요

✍️ 대본·제목기사·인스타·사진으로 기획 가이드와 1분 대본, 위 두 줄 제목까지
🎬 영상 재료유튜브 영상에서 주인공 얼굴이 나오는 장면만 골라 클립으로
📸 사진 수집최근 기사 사진 중 그 연예인 얼굴이 크게 나온 것만
✂️ 캡컷 느낌 편집AI 목소리 + 말하는 단어 강조 자막 + 댓글 카드 + 표지
▶️ 유튜브 자동 업로드제목·설명·태그를 채워서 올려줘요. 예약 공개도 돼요

설치 방법

  1. 위 ⬇ 윈도우용 다운로드를 눌러 StarShorts_Setup.exe 를 받아요
  2. 받은 파일을 더블클릭 → 설치 (1~2분)
    파란 창 “Windows의 PC 보호”가 뜨면 추가 정보 → 실행을 눌러주세요
  3. 바탕화면 🌟 스타 쇼츠 아이콘을 더블클릭하면 크롬에 프로그램이 열려요 (127.0.0.1:5252)
  4. 처음 켜면 로그인 화면이 나와요 — 받은 아이디·비밀번호를 넣어주세요
  5. 첫 화면 안내대로 ⚙️ 설정에서 제미나이 API 키와 내 채널 이름을 넣으면 끝!

자주 묻는 질문

내 작업이 다른 사람 컴퓨터로 가나요?

아니요. 프로그램은 각자 컴퓨터에서만 돌아가요. 키·로그인·만든 영상은 모두 내 컴퓨터에만 저장돼요.

무엇이 필요한가요?

윈도우 10/11 컴퓨터와 인터넷, 그리고 무료로 받을 수 있는 제미나이 API 키가 필요해요. 목소리는 무료 AI 목소리가 기본이고, 타입캐스트 키가 있으면 더 다양한 목소리를 쓸 수 있어요.

처음 켤 때 느려요

처음 한 번은 얼굴 인식 모델과 필요한 도구를 뒤에서 받느라 시간이 조금 걸려요. 다음부터는 빨라요.

저작권은 괜찮나요?

다른 사람 영상·사진을 쓸 때는 각 플랫폼 규칙과 저작권을 꼭 지켜주세요. 유튜브 검색의 “재사용 허용만” 필터를 쓰면 더 안전해요. 워터마크 지우기 같은 기능은 넣지 않았어요.
