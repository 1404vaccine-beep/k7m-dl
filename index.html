HOW IT WORKS

순서대로 따라가면 3단계로 끝

화면마다 다음 → 버튼만 누르면 돼요. 처음 써도 길을 잃지 않게 안내해 드려요.

1

재료·대본

SNS 링크 · 기사 · 유튜브 영상 · 내 사진을 한 화면에 모아요. 유튜브 무대에선 주인공 얼굴이 나온 장면만 클립으로 잘라요. 다 모으면 AI가 1분 대본과 위 두 줄 제목을 써요.

2

편집

모은 재료가 목소리 길이에 맞춰 알아서 깔려요. AI 목소리, 말하는 단어 강조 자막, 팬 댓글 카드, 효과음·배경음악, 표지까지.

3

업로드

제목·설명·태그를 확인하고 버튼 한 번에 유튜브로. 예약 공개도 돼요.

FEATURES

팬 쇼츠에 필요한 건 다 들어 있어요

캡컷 느낌의 편집기에서 끌어서 옮기고, 더블클릭해서 바로 고치세요.

🎙️

자연스러운 AI 목소리

무료 목소리부터 타입캐스트의 다양한 목소리까지. 영어는 읽는 법도 정할 수 있어요.

💬

말하는 단어 강조 자막

목소리에 맞춰 지금 읽는 단어만 색이 바뀌어요. 긴 줄은 알아서 두 줄로.

🗨️

진짜 팬 댓글 카드

유튜브의 실제 팬 댓글을 골라 영상 중간중간 띄워요. 지어낸 댓글은 쓰지 않아요.

🎯

얼굴 찾아 장면 자르기

긴 무대 영상에서 주인공이 나온 곳만. 얼굴이 가운데 오게 맞춰요.

🔊

효과음·배경음악

저작권 걱정 없는 기본 음악과 효과음. 효과음은 버튼 한 번에 자동 배치.

🖼️

표지(썸네일)

얼굴 잘 나온 장면을 찾아 빛나는 테두리·후광까지 넣어 줘요.

⏰

예약 업로드

1~1시간 반 뒤 자동 예약, 또는 원하는 시간에. 채널을 여러 개 써도 안 섞여요.

🔄

자동 업데이트

켤 때 새 버전이 있으면 알아서 바꿔요. 다시 설치할 필요 없어요.

FAQ

자주 묻는 질문

내 작업이 다른 사람 컴퓨터로 가나요?

아니요. 프로그램은 각자 컴퓨터에서만 돌아가요. 키·로그인·만든 영상은 모두 내 컴퓨터에만 저장돼요.

무엇이 필요한가요?

윈도우 10/11 컴퓨터, 인터넷, 무료로 받을 수 있는 제미나이 API 키가 필요해요. 목소리는 무료 AI 목소리가 기본이고, 타입캐스트 키가 있으면 더 다양한 목소리를 쓸 수 있어요. 유튜브에 올리려면 크롬이 있으면 좋아요.

처음 켤 때 느려요

처음 한 번은 얼굴 인식 모델과 필요한 도구를 뒤에서 받느라 시간이 조금 걸려요. 다음부터는 빨라요.

프로그램 창이 안 보여요

스타 쇼츠는 크롬 같은 브라우저 화면에서 열려요. 창을 닫았으면 작업 표시줄 오른쪽 아래(시계 옆) 🌟 아이콘을 누르면 다시 열려요. 끌 때는 아이콘을 오른쪽 클릭 → 프로그램 끄기.

저작권은 괜찮나요?

다른 사람 영상·사진을 쓸 때는 각 플랫폼 규칙과 저작권을 꼭 지켜 주세요. 유튜브 검색의 "재사용 허용만" 필터를 쓰면 더 안전해요. 워터마크 지우기 같은 기능은 넣지 않았어요.
